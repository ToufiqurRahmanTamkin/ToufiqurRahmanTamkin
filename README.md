## 🧠 Engineering Principles

<table>
<tr>
<td align="center" width="25%">

**🎯 Full Ownership**

I trace bugs from frontend to DB layer, own the deploy, and write the runbook. No handoffs, no excuses.

</td>
<td align="center" width="25%">

**⚡ Simplicity First**

Every abstraction must earn its place. I optimize for the engineer reading this code at 2am during an incident.

</td>
<td align="center" width="25%">

**📐 Design Before Code**

ADRs, ERDs, and sequence diagrams before the first function. Slow down to speed up.

</td>
<td align="center" width="25%">

**🔁 Ship → Measure → Improve**

Deploy early, instrument everything, iterate fast. Perfect is the enemy of deployed.

</td>
</tr>
<tr>
<td align="center" width="25%">

**🤖 AI-Augmented Velocity**

I leverage LLMs, local models, and automation to multiply engineering throughput without sacrificing quality.

</td>
<td align="center" width="25%">

**🔌 Integration Fluency**

Treat every third-party API as a dependency to be respected — versioned, rate-limited, idempotent, and monitored.

</td>
<td align="center" width="25%">

**🏗️ Build for Evolution**

Systems must outlive the team that built them. I document intent, not just implementation.

</td>
